SESSION 2: Building an APA Reference List

In this session I learned how to write a full reference list at the end of a paper using APA format. We practiced citing different types of sources like books, journal articles, websites, YouTube videos, and even ChatGPT. The format changes depending on the source type, so each one has its own rules for what comes first, how titles are written, and where the URL goes. This matters because a reference list gives the reader everything they need to find your sources and check your claims. It is also what separates your ideas from borrowed ones. The hardest part was citing journal articles because there are so many parts: author, year, article title, journal name, volume, issue, and page numbers. I got confused about which parts to italicize. I solved this by using the APA citation guide as a template and filling in each field one at a time instead of trying to remember the whole format from memory.
